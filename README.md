# Classic Crests - Retro Football Jerseys E-Commerce Website

**Classic Crests** is a user-centric, front-end e-commerce platform dedicated to offering retro football jerseys. The website features a clean and intuitive interface that allows users to easily browse and purchase vintage jerseys from various teams. While currently a front-end solution, the project showcases key e-commerce features and design choices that aim to enhance the user experience.

---

## Features

- **Product Gallery**: Displays a wide range of retro football jerseys with high-quality images and descriptions.
- **Product Filtering**: Allows users to filter jerseys by team, size, and price range for easier browsing.
- **Add to Cart**: Users can add products to their shopping cart for easy purchasing (cart functionality is front-end only at the moment).
- **Responsive Design**: The website is fully responsive and works seamlessly across desktops, tablets, and mobile devices.

---

## Technologies Used

- **HTML5**: For the basic structure and layout of the website.
- **CSS3**: For styling, with a focus on creating a visually appealing and responsive design.
- **JavaScript**: Used for implementing front-end functionality such as filtering products, adding to the cart, and toggling product details.
- **Bootstrap 4**: A popular CSS framework used for designing responsive layouts and components.
